# Kata & Frasa Terlarang — Indonesia

Kompilasi dari repo anti-slop Indonesia di GitHub + riset akademik (sumber lengkap di sources.md). Penanda paling tervalidasi penutur asli: **"hiruk pikuk"** — "kalau ada hiruk pikuk, pasti ChatGPT".

Cara pakai: pindai draf. Setiap temuan = **tulis ulang kalimatnya**, bukan cuma hapus frasa. Frasa klise menempel di kalimat kosong; hapus frasa saja sisanya tetap kosong.

## 1. Pembuka klise (hapus, mulai dari fakta/angka/adegan)

- "Di era digital yang serba cepat ini, …" / "Di era yang serba modern ini, …" / "Di zaman sekarang ini, …"
- "Seiring dengan perkembangan teknologi (yang semakin pesat), …" / "Seiring berjalannya waktu, …"
- "Dalam dunia X yang terus berkembang, …" / "Di tengah hiruk pikuk …" ← hiruk pikuk terlarang total
- "Tidak dapat dipungkiri bahwa …" / "Tak bisa dimungkiri, …" → nyatakan langsung
- "Seperti yang kita ketahui (bersama), …" → kalau semua tahu, tak perlu ditulis
- "Penting untuk dipahami/dicatat/diketahui bahwa …" → langsung isinya
- "Pernahkah Anda bertanya-tanya …?" / "Siapa yang tidak mengenal …?" → hapus
- "Mari kita menyelami/mengeksplorasi lebih dalam …" / "Sebelum membahas lebih lanjut, mari pahami dulu …" → langsung bahas
- "Artikel ini akan membahas …" / "Berikut adalah beberapa hal yang perlu Anda ketahui …" → pembuka itu jawaban, bukan janji
- "X memainkan peran yang sangat penting dalam …" → katakan X *ngerjain* apa
- "Dalam beberapa tahun terakhir, X mengalami pertumbuhan signifikan" → angka + sumber

## 2. Transisi klise (kuota: maks 1x per teks, jangan buka dua paragraf beruntun)

- "Selain itu," / "Tidak hanya itu," / "Terlebih lagi," / "Lebih lanjut," / "Tak kalah penting,"
- "Namun demikian," → "Namun," / "Tapi,"
- "Oleh karena itu," / "Dengan demikian," → "Jadi," atau gabung sebab-akibat
- "Sementara itu," / "Adapun," / "Selanjutnya," / "Dalam hal ini," / "Di sisi lain," (tanpa kontras nyata)
- "Perlu diingat bahwa …" / "Seperti yang telah disebutkan sebelumnya," / "Dengan kata lain,"

## 3. Penutup ritual

- "Sebagai kesimpulan," / "Kesimpulannya," / "Sebagai penutup," → tulis keputusannya, bukan labelnya
- "Nah, itulah tadi pembahasan tentang …" / "Demikianlah artikel …" → hapus
- "Semoga (artikel ini) bermanfaat!" / "Selamat mencoba!" / "Jadi, tunggu apa lagi?" / "Yuk, mulai sekarang!" → hapus
- "Jangan ragu untuk menghubungi kami" → "Hubungi kami kalau …"
- "Bagaimana menurut Anda? Tulis di kolom komentar!" → hapus

## 4. Klausa tack-on (kembaran -ing tack-on versi Indonesia)

Pola AI paling gampang dikenali: kalimat bagus, terus dikasih ekor analitis. ", menciptakan …" / ", menjadikannya …" / ", menandakan …" / ", menunjukkan bahwa …" / ", menjadikan X sebagai …"

- AI: "Perusahaan meluncurkan produk baru, menciptakan revolusi di industri ini."
- Manusia: "Perusahaan meluncurkan produk baru." (Selesai. Kalau ekornya bawa info beneran, jadiin kalimat sendiri.)

## 5. Puffery & inflasi signifikansi

- "bukti nyata komitmen …" / "sebuah testament untuk …" / "momentum baru dalam …"
- "berperan penting/krusial/vital dalam …" / "memegang peranan kunci …"
- "menandai babak baru" / "titik balik" / "langkah strategis" (tanpa fakta)
- "menghadirkan pengalaman yang seamless/mulus" / "solusi terdepan" / "inovasi revolusioner"
- Angka puffed: "ribuan pengguna" (tanpa sumber), "lebih dari sekadar …"

## 6. Cringe / over-gaul (dari humanizer-id)

- Slang > 2 per paragraf → kurangi. Slang itu bumbu, bukan makanan.
- "bro/cuy/anjay/wkwk" di tiap kalimat → noise.
- Campur register: "gue/lo" vs "aku/kamu" dalam satu teks → pilih satu, konsisten.
- Buzzword Inggris di teks Indonesia: slay, literally game-changer, seamless, groundbreaking, testament, leverage, robust.
- Gen Alpha di konten dewasa: skibidi, sigma, ohio, gyatt, mewing.
- Uji baca keras-keras: kalau kerasa "brand pura-pura gen-Z" atau "robot formal" → rewrite.

## 7. Ejaan/ragam yang sering salah (dari bahasa-skills, EYD V)

- "di mana" sebagai penghubung ("kasus di mana …") → "yang" atau pecah kalimatnya.
- "dimana/dikarenakan/dengan demikian" beruntun → variasikan atau potong.
- "yang mana" → ulangi kata bendaannya: "revisi kedua; revisi ini …"
- Kata tidak baku di teks formal: "kayak, gini, udah, banget" → simpan buat chat santai aja.
